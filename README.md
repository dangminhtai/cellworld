# CELLWORLD

Mô phỏng 100 tế bào trên trình duyệt.

- Ban đầu 100 tế bào, không sinh sản.
- Di chuyển ngẫu nhiên, phát hiện thức ăn trong bán kính 90px.
- Mỗi lần ăn tăng bộ đếm một đơn vị; chỉ chết khi ăn hạt thứ 101.
- Không chết vì đói, tuổi tác hay hết năng lượng.

Mở `index.html` để xem mô phỏng. Chạy trên GitHub Pages nếu được bật trong phần Settings > Pages.
